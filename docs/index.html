iptv_org_api

Fully typed, cached, isolate-parsed relational Dart client for querying global live channels, streams, categories, languages, and regions from the open iptv-org dataset.

✨ AI Agent Prompt (skill.sh compatible)
Run `npx skills use "https://github.com/flutter/agent-plugins" --skill "flutter-apply-architecture-best-practices"`

Key Package Capabilities

🔍

Relational Queries

Filter global IPTV channels by category, region, language, country, and stream health status.

⚡

Isolate Offloaded Parsing

Parse 30,000+ channel records off the main thread with zero frame stutter.

💾

In-Memory & Persistent Caching

Built-in caching engine for instant startup and offline capability.
